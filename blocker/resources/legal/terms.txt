2. Calendar access and the scheduling service

calendar-blocker finds time for activities within the days, time windows,
durations, recurrence, and priorities recorded in its approved configuration.
Google Calendar is the currently supported provider.

Connecting Google authorizes ongoing access through a stored refresh token.
The Service reads calendars available to connected accounts and manages events
on a separate app-created calendar, normally named "Auto Blocks." It cannot use
its requested write permission to edit or delete events on calendars it did
not create. Connecting alone does not add a scheduling request or publish your
account to the configuration repository.

You authorize the Service to perform the following actions as necessary to
carry out approved requests that include you:
- Read calendar lists and relevant events to determine availability.
- Create an app-managed calendar when you organize a scheduled activity.
- Create, move, update, and delete future app-managed events as requests and
  availability change.
- Send calendar invitations and updates to participants in shared activities.
- Read participant responses and remove a shared block when a guest declines.

An approved request can recur and continue generating calendar events until
it is removed or access is revoked. Higher-priority requests may displace
lower-priority app-managed blocks. Unmanaged events take precedence. Events
in later weeks may be re-optimized, so an existing block is not a guarantee of
a fixed future time. Blocks that have started are not changed by the scheduler.

Shared requests require usable calendar connections for all participants. An
unavailable participant, expired authorization, lack of a suitable slot, an API
failure, or a service outage can prevent scheduling. The scheduler runs
periodically, normally hourly. Submitting or merging a request does not cause
an immediate booking or guarantee that an event will be scheduled. Time windows
use the shared timezone shown in the website, rather than necessarily the
browser's or each participant's local timezone.
